## 项目简介

网页总结工具是一个本地运行的网页小工具：输入任意网页地址，自动抓取正文并生成中文摘要，支持中英文页面。

## 核心功能

- 输入 URL，抓取正文并抽取标题、段落与正文
- 调用 AI 生成中文摘要、要点与关键词
- 支持英文网页，输出中文摘要
- AI 服务不可用时回退到抽取式摘要，保证页面永远有结果
- 零第三方依赖的 Node.js 静态服务，防目录穿越

## 技术要点

- Node.js 内置 `http` 模块，零依赖
- 中文站点编码识别（`gb2312` → `gbk`），使用 `TextDecoder` 解码
- 正文提取优先 `<article>` / `<main>`，剥离脚本、导航与页脚
- 抓取超时、重定向与失败兜底
- 原生 HTML / CSS / JS 前端，无 CDN 依赖

## 收获

这个项目让我理解了「抓取 → 清洗 → 摘要 → 展示」的完整数据链路，也练习了在外部服务不稳定时如何设计降级方案。
