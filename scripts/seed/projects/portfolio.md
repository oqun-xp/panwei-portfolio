## 项目简介

这是你正在浏览的个人作品集网站。目标不是做一个静态简历，而是做一个可以长期维护的内容系统：前台展示，后台编辑，数据持久化。

## 核心功能

- 深色星空主题，Canvas 粒子背景，响应式布局
- 首页展示个人信息、技能、精选项目与最新文章
- 项目列表 / 详情、博客列表 / 详情
- 独立后台：登录、仪表盘、个人信息、技能、项目、博客、留言、站点设置
- Markdown 编辑器与实时预览
- 联系表单与后台留言管理

## 技术架构

- **前端**：React 18 + TypeScript + Vite + Tailwind CSS + React Router
- **后端**：Vercel Serverless Functions
- **持久化**：GitHub 私有仓库 `personal-site-data/content.json`
- **鉴权**：HMAC-SHA256 签名 token，12 小时过期
- **部署**：Vercel

## 设计要点

- 背景 `#05070D`，强调色可在后台配置
- 星空粒子在移动端自动降采样，尊重减少动效设置
- 所有写接口服务端校验，token 不落库、密码不进前端
- 本地开发无 token 时自动回退到 `data/content.json`
